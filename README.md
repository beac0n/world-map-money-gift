# World map money gift – laser cut

A wedding money gift made from two A5 plywood boards. The continents are cut
out of the front board, so the banknotes behind them show through. Leather cords
through the four corner holes tie both boards together.

The SVG files are generated by one Python script, so you can change the names,
the date and the phrase.

## Quick start

You need [uv](https://docs.astral.sh/uv/). It installs the Python dependencies
on the fly. On the first run the script also downloads the fonts and the map
data (about 2 MB) into `downloads/`; see [Credits](#credits).

```sh
uv run make_gift.py --names "Hildegard & Waldemar" --date "12. Juni 2027"
```

This writes to `output/`:

| File            | What                                                         |
|-----------------|--------------------------------------------------------------|
| `front_3mm.svg` | Front board: outline, cord holes, map cut-outs and engraving |
| `back_3mm.svg`  | Back board: outline and cord holes                           |
| `preview.svg`   | Coloured picture of the finished front (not for the laser)   |

### Options

| Option     | Default                                | Meaning                        |
|------------|----------------------------------------|--------------------------------|
| `--names`  | `Hildegard & Waldemar`                 | Names under the map            |
| `--date`   | *(none)*                               | Date under the names           |
| `--phrase` | `Die schönste Reise beginnt zu zweit`  | Line above the map             |
| `--out`    | `output/`                              | Output directory               |

Text that is too long is scaled down until it fits. The script stops with an
error if any engraving would run into the map or a cord hole.

## Laser settings

- **Material:** 3 mm plywood, two A5 boards (210 × 148 mm). Each SVG page is
  exactly one board.
- **Colours:** red `#e01b24` = cut, blue `#3584e4` = engrave.
- **Engraving:** filled areas (text, compass rose) are already
  hatched with lines 0.2 mm apart. Run the blue layer as a line or score
  operation, not as a fill. If your laser software fills shapes itself, you can
  do that instead and ignore the hatch lines.
- **Cord holes:** 4 mm, for suede cord of about 3 mm.

## Assembly

1. Cut and engrave the front board, then cut the back board.
2. Lay the banknotes on the back board and put the front board on top.
3. Thread a cord through the two holes on each side and tie a bow.

## How the map is made

- **Projection:** [Equal Earth](https://en.wikipedia.org/wiki/Equal_Earth_projection).
  It is equal-area, so countries are shown at their true relative size: Africa is
  big and Greenland small, unlike Mercator. The map is centred on 11° E, with
  Europe in the middle. Antarctica is left out.
- **Minimum wood width:** no wood between two cut-outs is thinner than 1.5 mm.
  Narrow inlets and fjords are filled in and become part of the cut-out. Narrow
  straits between two land masses or two seas (Channel, Gibraltar, Bosporus,
  Red Sea …) are widened into thin wood bridges, so seas like the Mediterranean
  or the Baltic stay attached to the board.
- **Small islands:** islands too small to cut cleanly (under 0.8 mm²) are left
  out.

All sizes and limits are constants at the top of `make_gift.py`.
